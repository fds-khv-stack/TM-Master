## Реализованные конверсионные «фишки»
- Sticky-кнопка записи (появляется при скролле) + плавающие WhatsApp/Telegram.
- Анимированные счётчики (рейтинг, оценки, отзывы).
- Появление блоков при прокрутке (scroll-reveal, IntersectionObserver).
- Интерактивный слайдер «До/После» (мышь + тач).
- Hover-микроанимации на карточках, плавный скролл по якорям, лёгкий tilt/параллакс на главном экране, бегущая строка (лофт), барберская полоса (классика).
- Адаптив (бургер-меню на мобильных).
